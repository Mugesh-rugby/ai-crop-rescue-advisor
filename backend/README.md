# AI Crop Rescue Advisor – Python Inference Backend

This FastAPI server provides real plant-disease predictions using the
PyTorch EfficientNetV2-S model trained by `training/train_small.py`.

---

## Prerequisites

1. **Train the model** (from the project root):

```bash
cd training
python train_small.py
```

This saves `checkpoints/plant_disease_best.pth` and `checkpoints/labels.json`.

2. **Create a virtual environment** (recommended):

```bash
cd backend
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate
```

3. **Install dependencies**:

```bash
pip install -r requirements.txt
```

---

## Running the Backend

```bash
cd backend
uvicorn main:app --reload --port 8000
```

The server starts at **http://localhost:8000**.

---

## API Endpoints

| Method | Path       | Description                              |
|--------|------------|------------------------------------------|
| GET    | `/health`  | Check if model is loaded                 |
| POST   | `/predict` | Upload an image → returns disease class  |
| POST   | `/chat`    | Send farming questions to Groq or Grok   |

### Chat provider configuration

Create `backend/.env` or `backend/.env.local` and add **one** provider key,
then restart the backend:

```env
# Groq (recommended)
GROQ_API_KEY=your_groq_key
# Optional: override the default model
# GROQ_MODEL=openai/gpt-oss-20b

# Or xAI Grok
# GROK_API_KEY=your_xai_key
# GROK_MODEL=grok-3-mini
```

The frontend sends chat requests to the Python backend through its `/api/chat`
proxy. Keep these keys in `backend/.env`; do not add them to a `NEXT_PUBLIC_*`
variable or commit the file.

### POST /predict

**Request**: `multipart/form-data` with field `file` (JPEG / PNG / WEBP image)

**Response**:
```json
{
  "className": "Tomato___Early_blight",
  "crop": "Tomato",
  "condition": "Early blight",
  "isHealthy": false,
  "confidence": 0.923456,
  "topK": [
    { "className": "Tomato___Early_blight", "confidence": 0.923456 },
    { "className": "Tomato___Late_blight",  "confidence": 0.043211 },
    ...
  ]
}
```
